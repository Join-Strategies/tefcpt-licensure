# tefcpt-licensure-page

Participant-facing **Licensure & Exam Fees** page for tefcpt.org. Repo is the design source-of-truth and WP deployment scaffold for Workstream 3 of the TEF-CPT engagement.

The MVP delivers a public page on tefcpt.org with one card per profession, surfacing the right Form 1 PDF, NYSED checklist, and Asana intake form(s) for each. The repo is structured to evolve toward either a standalone microsite or a WordPress plugin.

## Quickstart

```bash
npm install
npm run dev
```

Then open the URL Astro prints (typically `http://localhost:4321`).
